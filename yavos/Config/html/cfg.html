Speaker Volume Command


Note: the %s placeholder is used to
denote where the actual real-time
value will be inserted. For example
to set the speaker volume on Ubuntu
you would enter

amixer -D pulse sset Master %s

Where '%s' will be replaced with
an actual value at run time so the
actual command executed would be

amixer -D pulse sset Master 50%
