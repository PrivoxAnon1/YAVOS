Developer Documentation

This section covers TTS and STT drivers and how to connect to a YAVOS server from a remote device. It should be noted these instructions are for easy to use command line terminal operation. For more production oriented systems it is recommended you install remote audio in/out as systemd services on Ubuntu or equivilent for MacOS or Windows. The same for the configuration server if the configuration will change frequently.
